# Family Level Ups

Private site for Joey, Maverick, and Ellie. The home page is the Family Level-Ups Record: notes and videos from the family.

It is published with GitHub Pages from the `main` branch at <https://familylevelups.github.io/>.

Search engines are asked to stay out: every page sends `noindex, nofollow`, and `robots.txt` disallows all crawlers. There is no sitemap.

Please keep the link in the family.

## Preview locally

From this folder:

```sh
python3 -m http.server 8080
```

Then open <http://127.0.0.1:8080/>.
